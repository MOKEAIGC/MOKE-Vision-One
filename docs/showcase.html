// Infinite Canvas

无限画布 · 节点式创作流

把每个生成步骤抽象成节点，自由拖拽连线，构建可视化的创作流水线。支持画布持久化、回收站恢复与实时协作。

  • 多种节点类型：生成器 / 图像 / 视频 / LLM / 提示词 / 循环 / 输出 / 智能 Composer
  • 缩略图导航 Minimap、连线层、画布工具栏与时间线管理
  • 服务端持久化存储，支持回收站与一键恢复

// Director 3D

3D 导演台 · 三维分镜运镜

在三维场景中放置角色、规划走位、控制相机轨迹，用真实的镜头语言指导 AI 生成，输出分镜稿与运镜参考。

  • 场景编辑、调度板、视口控制与坐标 / 相机辅助叠层
  • 内置 3D 角色模型，按场景真实比例归一化（180cm）、脚底贴地
  • 场景导出、截图与主程序捕获桥接
